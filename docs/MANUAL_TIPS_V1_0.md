# v1.0 – ruční výběr tipů

Predikce a statistika sázek jsou oddělené.

- Výpočet kola pouze zobrazí kandidáty.
- Změna fair filtru pouze změní zobrazení.
- Každý kandidát má checkbox.
- Do statistiky vstoupí pouze tipy, které uživatel zaškrtne a potvrdí tlačítkem Uložit vybrané tipy.
- Stejný tip nelze uložit podruhé.
- GitHub Actions automaticky pouze vyhodnocuje již uložené tipy.
- Staré automatické záznamy jsou označené jako legacy_auto.
