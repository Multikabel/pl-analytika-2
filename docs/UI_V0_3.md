# UI v0.3

První tabulková verze aplikace.

## Spuštění

Po prvním setupu:

```text
run_app.bat
```

První spuštění na novém PC:

```text
setup_and_run.bat
```

## Princip UI

Aplikace je schválně postavená jako hustý tabulkový dashboard:

- minimum navigace,
- hlavní týmové statistiky na jedné obrazovce,
- zápas se zadává v levém panelu,
- výsledkem je okamžitě souhrn Fauly / Rohy / ŽK,
- detailní O/U pravděpodobnosti a fair kurzy jsou v tabulkách,
- model lze porovnat s baseline.

Toto je první funkční UI vrstva. Další iterace má přidat seznam celého hracího kola a screening value příležitostí.
